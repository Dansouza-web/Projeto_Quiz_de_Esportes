# 🏆 Quiz de Esportes

Quiz interativo desenvolvido com **HTML, CSS e JavaScript**, criado para praticar lógica de programação e manipulação do DOM.

## 📌 Sobre o projeto

O Quiz de Esportes apresenta perguntas relacionadas ao mundo dos esportes e permite que o usuário selecione uma alternativa.

O sistema verifica a resposta escolhida, informa se ela está correta ou incorreta, contabiliza a pontuação e, ao final, apresenta o resultado do usuário.

## 🚀 Funcionalidades

- [x] Exibição das perguntas
- [x] Criação dinâmica das alternativas
- [x] Verificação das respostas
- [x] Indicação de resposta correta e incorreta
- [x] Bloqueio das alternativas após a resposta
- [x] Sistema de pontuação
- [x] Botão para avançar para a próxima pergunta
- [x] Resultado final
- [x] Opção de jogar novamente
